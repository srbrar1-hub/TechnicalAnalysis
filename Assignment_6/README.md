Project Description

This project creates an interactive Stock Portfolio Technical Analysis Dashboard using R Shiny. It retrieves historical stock market data from Yahoo Finance and displays stock price trends using different charts.

Features
Historical stock data using quantmod
Interactive R Shiny dashboard
Daily, weekly, and monthly time frames
Line, area, and candlestick charts
Moving Averages (20-day and 50-day)
Relative Strength Index (RSI)
Moving Average Convergence Divergence (MACD)
Buy and Sell trading signals
Customizable technical indicators
Technologies Used

R, Shiny, ggplot2, quantmod, TTR, and Yahoo Finance.

How to Run
Install the required R packages: shiny, ggplot2, quantmod, and TTR.
Open app.R in RStudio.
Click Run App.
Select a stock ticker, date range, chart type, and technical indicators.
